# Проверка программы восстановления, версия 2 — 12.10.2026

Реализованы несколько дополняющих способов чтения полной копии флешки. Успешное восстановление проверено на искусственных образах и заранее известных фотографиях. Флешка пользователя не подключена; её файлы не читались.

## Что изменилось

- `FilesystemRecovery.cs`: удалённые записи FAT12/FAT16/FAT32/exFAT, имена и сведения о цепочках кластеров; известные занятые участки исключены. Стертая цепочка и неоднозначная принадлежность кластеров помечаются как предположение. Частичные результаты имеют пометку `PARTIAL`.
- `AdvancedEngines.cs`: TestDisk восстанавливает NTFS по MFT; корректное завершение проверяется по журналу, ошибки разделов отражаются в результате. Для PhotoRec включены шаг 512 байт, попытки сборки фрагментированных JPEG и сохранение повреждённых кандидатов.
- `ExtraPhotoSearch.cs`: JPEG/PNG на произвольном байтовом смещении, включая встроенные фотографии. JPEG проверяется по маркерам и окончанию, PNG — по последовательности блоков и CRC32. Отсутствующие части не синтезируются.
- `PhotoCatalog.cs`: проверка декодирования, размеры, EXIF дата при наличии, SHA256 дубликаты, локальные миниатюры, поиск и фильтры в HTML, JSON/CSV. Целые и повреждённые кандидаты различаются; неопределённые предположения о цепочках не скрываются.
- `RecoveryPipeline.cs`: способы запускаются последовательно, ошибка одного способа не теряет результаты остальных; журнал этапов позволяет увидеть неполный поиск.

## Практические пределы

Опыты подтверждают конкретные возможности, а не равенство с коммерческими программами на любой флешке. Сравнение с платными аналогами на одинаковом реальном носителе не проводилось. Искусственная FAT-фотография использует сохранившуюся цепочку; после обычного удаления FAT может её стереть, и точную сборку разнесённых частей восстановить по этой цепочке уже нельзя.

Поиск по сигнатурам может создавать ложные совпадения и дубликаты; на искусственных нулевых областях PhotoRec создавал ложные `.dovecot`. Счётчик показывает сохранённые кандидаты. Галерея проверяет изображения и группирует их, сохраняя все результаты на диске. Успешное декодирование не доказывает восстановление каждого исходного пикселя.

Предпросмотр ограничен 128 МиБ, 60 млн пикселей, 32 768 пикселей по стороне. Дополнительный JPEG/PNG-поиск ограничен 128 МиБ на изображение. HEIC/RAW/WebP/AVIF требуют внешней проверки. Зашифрованные/сжатые NTFS, сложные повреждённые MFT, EBR/4-КиБ варианты NTFS и произвольные случаи JPEG-фрагментации не доказаны тестами. Восстановление FAT/exFAT имеет пределы обхода и объёма результатов; достижение предела отражается как неполный этап.

Проверка галереи в живом браузере не завершилась: встроенное окно браузера не подключилось. Генерация, данные, ссылки, безопасная вставка, признаки ограниченной выдачи и структура фильтров проверены; визуальный и интерактивный прогон HTML в браузере остаётся непроверенным.

Физический USB-источник не читался. Код открывает его только на чтение, затем поиск использует образ под блокировкой записи. Защита от записи со стороны Windows и других программ не устанавливается. Программа не форматирует накопитель и не исправляет файловую систему. Перезаписанные данные и отсутствие нужной фотографии в копии нельзя исправить программным поиском.

## Следующий шаг

Перенести всю папку `Готовая программа` на другой компьютер, подключить нужную флешку и запустить усиленный поиск. Оценить восстановление фотографии по самому изображению; при необходимости сохранить полную `usb.dd` для дальнейшей работы.
