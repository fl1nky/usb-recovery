# Версия 3 — состояние реализации

Обновлено **13 октября 2026**. План принят 12 октября; проект остаётся отдельной папкой без Git. Репозитории `C:\KronBars` не изменяются.

## Реализовано

- Сохранён конвейер версии 2: read-only USB-образ, FAT/exFAT, NTFS/TestDisk, PhotoRec, дополнительный JPEG/PNG и каталог фотографий.
- Добавлены `IRecoverySource` для папки, обычного образа, локальной копии и телефона; WPD/MTP и дополнительный ADB. Логические источники не направляются в FAT/NTFS-поиск.
- Рабочая копия `snapshot`, SHA256/метаданные/происхождение, `.partial`, отмена, продолжение и проверка завершённых файлов реализованы.
- Новый Windows-экран содержит выбор источника/устройства/папки, маскированные поля секретов и разделы «Фотографии», «Переписки», «Источники и замечания».
- Переносимый Python 3.12 helper собран: Telegram JSON/HTML; WhatsApp TXT/ZIP, Android/iPhone SQLite, crypt12/14/15; iPhone Manifest и поддерживаемое шифрование iOS 13+; WebP/HEIC/HEIF, встроенные фото и фрагменты.
- Локальные `messages.jsonl`, индекс SQLite FTS5, HTML и JSON-метаданные сохраняют происхождение и категории доказательств. HTML источника читается как данные; внешние запросы запрещены в созданном архиве.
- Два native Signal helper реализованы. Modern вызывает official FramesReader pinned libsignal; legacy переведён на pinned FileDecryptor signalbackup-tools. Секреты передаются через stdin, аутентификация обязательна, default test key отсутствует.
- Исходники, pinned зависимости, offline wheels/Cargo vendor, лицензии, сборочные сценарии и инструкции подготовлены для упаковки.

Source copying: 15 проверок; image/backup abstractions: 7; stdin/отмена: 12; Engine: 19; Signal final binaries: 15; независимый конвейер: 5; C# → frozen Python: 28; форматы через переносимый EXE с ограниченным PATH: 12. Native WPD manager перечислен успешно, подключённых устройств 0. Регрессии версии 2 прошли. Доказательства и точная таблица форматов — [V3-VALIDATION.md](V3-VALIDATION.md).

## Выпуск

Готовая папка обновлена и проверена: 39 запусков переносимого обработчика по всем форматам и сквозной импорт при запрете исходящих соединений Windows Firewall, без Python в PATH. Временные сетевые правила удалены. Три сценария версии 2 (произвольные смещения, NTFS, фрагментированный FAT) повторены из готовой папки; все исходные SHA256 сохранены. ADB запускается из готовой папки с ограниченным PATH. Исходники, зависимости и лицензии включены; `package-sha256.json` содержит 207 исполняемых файлов и библиотек, все хеши проверены.

Запуск: `Готовая программа/USB-Recovery.exe`. Инструкция: `Готовая программа/НАЧНИ ЗДЕСЬ.txt`. Размер комплекта с исходниками и зависимостями — около 528 МиБ. Основной EXE SHA256: `C41CCA5B614B19A891E274A7E07D3108A88FE1D84634F3560DF7F4E301FC6CB6`.

## Границы

Настоящие Android/iPhone, физическая флешка пользователя и аппаратные USB-сценарии не проверены. Не выполнено сравнение с платными программами на одном носителе. Modern Signal собран Rust 1.98.1 для Windows GNU вследствие отсутствия MSVC; commit/формат сохранены, отклонение target явно описано в [THIRD-PARTY.md](../third-party.md).

Облачный вход, Secure Backups Signal в облаке, root/jailbreak, обход блокировки, создание новых backups и запись обратно в мессенджеры исключены. «Ничего не найдено» относится к доступным источникам и не доказывает уничтожение данных.

## Обновление интерфейса

Строгая боковая навигация и native-поиск Telegram/WhatsApp/Signal, отдельные Android/iPhone/импорт/флешка. Проверены 120 компоновок, 16 Python-тестов, 12 native-проверок и 13 сквозных проверок поиска, включая прогон из готовой папки с запретом сети и без Python в PATH. См. UI-UPGRADE.md.
