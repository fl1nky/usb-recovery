# Проверка глубокого поиска USB

27 октября 2026. Рабочий каталог — локальный самостоятельный артефакт `usb-recovery`, без Git-репозитория; репозитории KronBars не менялись. Реальные USB-диски и пользовательские данные в проверках не открывались.

## Что изменено

`RecoveryOptions` и `RecoverySettingsPanel` связывают 17 галочек с реальными методами/форматами; варианты и результаты сохраняются в JSON. `BootScout` выполняет полный проход по загрузочным сигнатурам и передаёт кандидатов проверяющим парсерам. FAT32/exFAT поддерживают резервную загрузочную запись, FAT12/16/32 — независимую вторую FAT. Для потерянного NTFS строится временный вид раздела; восстановление boot при необходимости происходит только в нём, затем TestDisk undelete. Рабочий вид удаляется.

`ContainerCarver` ищет непрерывные контейнеры по любому байту, в том числе на границе блоков; центральный каталог ZIP сопоставляется с локальными заголовками, RIFF проверяется по длинам блоков, BMFF — по цепочке блоков и наличию media/metadata. Повреждённые/неполные варианты не объявляются полноценными файлами. Полная CRC/декодируемость содержимого ZIP/PDF/видео не утверждается.

`ResilientCapture` — ограниченный съём с картой непрочитанных диапазонов, не GNU ddrescue: крупный блок → 64 КиБ → сектор, одна повторная секторная попытка, максимум 4096 дополнительных секторных проб. Нулевые заполнители отражаются в статусе образа и общем каталоге. EOF/отключение/отмена не дают успешный полный образ.

`RecoveryCatalog`/`RecoveryFilesForm` дают общий список, фильтры, SHA256-группировку с сохранением всех копий и отдельный экспорт выбранного с повторной проверкой содержимого. Выгрузка не меняет оригиналы результатов. Запрет исходного носителя использует номер диска и сохранённые Serial/UniqueId, если они есть. Физическая проверка переподключения на настоящем USB не выполнялась.

Обычные внешние DD/IMG/RAW можно анализировать с базовой SHA256, сохранённой в новой папке результатов. Это проверка неизменности текущего файла, не подтверждение его первоначальной полноты. `.partial` отвергается. Сжатые forensic-образы не поддерживаются напрямую.

## Повторение проверок

`tests/DeepRecoveryFixtures.py` создаёт независимые контейнерные образцы. `DeepRecoveryTests.cs` компилируется с исходниками программы и `tests/FilesystemRecoveryTests.cs`, entry point `DeepRecoveryTests`; аргумент — корень проекта. В тестах требуются включённые PhotoRec/TestDisk и существующий искусственный `tests/AdvancedNtfs.dd`. Процессы работают только с обычными файлами образов.

Нативный UI проверяется `DeepRecoveryUiTests.cs`; автоматическое обнаружение устройств отключено. Изображения интерфейса: `tests/USB-methods.png`, `tests/USB-results.png`.

`tests/UsbOfflineTests.ps1 -ApplicationDirectory <готовая папка>` отдельно проверяет уже собранный EXE и фактически включённые инструменты с блокировкой их исходящих соединений и Python вне PATH. Финальное состояние фиксируется в `tests/UsbOffline-validation.json`. Контрольные суммы готовой папки находятся в `package-sha256.json`.

## Границы

Полнота восстановления любого удалённого файла, равенство всем функциям платных продуктов, аппаратное восстановление и обход шифрования не заявляются. Дополнительные контейнерные проходы имеют ограничения, изложенные в USB-DEEP-GUIDE.md; основной PhotoRec остаётся отдельным механизмом. Наличие подписи или корректного контейнера не доказывает, что восстановлены все нужные данные.

Первичные источники: [TestDisk/PhotoRec scripted run](https://www.cgsecurity.org/wiki/Scripted_run), [исходники TestDisk 7.2](https://www.cgsecurity.org/testdisk-7.2.tar.bz2), [GNU ddrescue](https://www.gnu.org/software/ddrescue/manual/ddrescue_manual.html). Имена обработчиков PhotoRec сверены с исходниками именно включённой версии 7.2 и проверены запуском; TIFF/RIFF/MOV охватывают несколько расширений. Исходный архив TestDisk и SHA256 теперь включены в поставку.

Все временные правила удалены. Совпали SHA256 всех 159 исполняемых частей. Результаты: tests/UsbOfflineTests.result.txt, tests/UsbOffline-validation.json, tests/UsbPackage-validation.json. Реальные устройства не проверялись.
