# Предоставленные дампы Java / Android

В Telegram выбери **«Источник… → Дамп памяти / файл…»**, укажи свою сохранённую копию и нажми **«Анализировать»**. Дальше доступны обычные ключевые слова и переключатель регулярных выражений

Обработчик распознаёт HPROF по заголовку, в том числе без расширения. Он связывает известный класс `TLRPC$TL_message` с родительским `Message`, строкой и объектами получателя/автора. Результат остаётся **текстовым фрагментом**: ID и дата предположительные, аккаунт, происхождение из настоящего приложения и факт удаления неизвестны. Идентификатор объекта относится к файлу дампа и не означает доступ к памяти телефона

Поддержаны идентификаторы 4/8 байт, один полный либо один сегментированный снимок, Android `char[]` и компактные строки при известном порядке байтов. Несколько полных снимков, неизвестные подзаписи и повреждённое обрамление отклоняются. Границы работы и отмена ограничивают чтение; временный индекс удаляется. До публикации проверяется неизменность SHA256 источника

**Проверено:** 14 исходных и 19 независимо написанных тестов, настоящий HPROF собственного JVM с искусственными Telegram-подобными классами, 103 проверки готового helper и C# поиска. Проверены Unicode, многострочные regex, физические хеши, неизвестные поля и отсутствие посторонних строк в результатах графа

Это не проверка настоящего Telegram на Android. Программа не получает дамп процесса с телефона, не обходит блокировку, не извлекает закрытый кэш через обычный USB и не гарантирует наличие удалённых сообщений в предоставленной копии

Воспроизведение для разработчика:

```powershell
.build/engine-env/Scripts/python.exe tests/AndroidHeapTests.py
.build/engine-env/Scripts/python.exe tests/AndroidHeapAuditTests.py
.build/engine-env/Scripts/python.exe tests/build_telegram_heap_fixtures.py .build/telegram-heap-portable-fixtures
```

Для создания независимого контрольного дампа нужен установленный JDK; готовому приложению он не требуется. Генератор использует только запущенный им собственный JVM. Существующий дамп не перезаписывается

Формат: [OpenJDK HPROF](https://cr.openjdk.org/~rpatil/webrev.01/raw_files/new/src/share/demo/jvmti/hprof/manual.html), [реализация Android ART](https://android.googlesource.com/platform/art/+/9a37efc/runtime/hprof/hprof.cc)
