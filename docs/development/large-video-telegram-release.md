# Большие видео и локальные базы Telegram

В этом обновлении сборка поддерживаемых MP4/MOV читает выбранные диапазоны источника и записывает результат потоком. Весь ролик и копии всех блоков больше не удерживаются в памяти. Поиск сначала разбирает контейнер и строит нужные запросы; посторонние сигнатуры другого видеокодека не заполняют общий индекс

| Проверка | Измеренный результат | Граница вывода |
|---|---|---|
| Девять образов с настоящими роликами | Шесть раскладок дали эталонные байты; максимальный файл — 41 269 003 байта; один неоднозначный вариант отклонён, два неполных поиска ограничены | Собственные образцы, не общий процент восстановления |
| Дополнительные независимые образы | Один ролик 24,5 МиБ восстановлен точно в двух раскладках; случайные данные без ложного файла, отмена и лимит проверки | Две раскладки другого ролика с непрозрачными фрагментами остались невосстановленными |
| Старые базы Telegram | V7: 0/20, V8: 20/20 целевых попаданий в четырёх примерах по пять повторённых сообщений | Сравнивался настоящий helper, не платные программы и не реальные телефоны |
| Длинные сообщения | Видимый участок настоящего совпадения, полный текст страницами, JSONL/SQLite, Unicode и проверка отпечатка записи | Предельный размер записи 4 МиБ, индекс до 8 ГиБ |

Для видео различаются точное совпадение с известным тестовым оригиналом и структурный кандидат из неизвестного источника. В реальном поиске непрозрачные видеоданные, принадлежность файла и факт удаления не удостоверяются. Неоднозначность не разрешается случайным выбором

Проверки готовой сборки: **26 543 проверки в 55 наборах**: 26 390 / 50 основных, 137 / 4 Telegram и 16 / 1 USB. Сеть для проверяемых программ была заблокирована, Python отсутствовал в ограниченном PATH. Отдельные проверки искусственного интерфейса/протокола и исходников не прибавляются к этому числу. Личные устройства не проверялись

Это обновление не подтверждает замену всех коммерческих инструментов. APFS/RAID/BitLocker и восстановление на личных устройствах имеют собственные границы проверки
