# Progressive JPEG, ext4, Linux MD и предоставленные HPROF

Приёмка следующего выпуска после `v2026.10.30-media-telegram`. Программа и обработчик собраны заново; старые числа проверок не перенесены на новые исполняемые файлы

| Проверка готовой сборки | Результат |
|---|---|
| Основной офлайн-набор | 6972 проверки, 34 набора |
| Telegram | 137 проверок, 4 набора; новые HPROF-проверки отдельно включены в основной набор |
| USB | 16 проверок; обычные искусственные файлы, без физического носителя |
| Progressive JPEG | 160 проверок: 7 независимых изображений, обычные/раздельные entropy scans, карта байтов, частичная точность, каталог и продолжение |
| Предоставленный HPROF | 103 проверки готового обработчика, 14 исходных и 19 независимых тестов; собственный настоящий JVM с искусственными классами |
| ext4 | 359 проверок на 36 образах e2fsprogs, 18 проверок конвейера и 28 независимых проверок происхождения |
| Linux MD | 2345 основных, 72 независимых и 20 проверок элементов интерфейса |

Перечисленные специализированные проверки входят в общие 6972 и не прибавляются к ним повторно. На время приёмки сеть приложений блокировалась Windows Firewall, Python отсутствовал в PATH; временные правила удалены. Обработчик поставляется вместе с Python и зависимостями

Сборка обработчика запустила 20 исходных наборов: 317 объявленных тестов, 316 выполнены, один внешний benchmark-тест требует отдельного `--external` и пропущен в обычном запуске. Новый независимый медиапрогон и его ограничения приведены в [протоколе сравнения](fragmented-media-benchmark.md)

Хеши исполняемых файлов, тестовых исходников и журналов связываются в `source/tests/RecoveryOctober30-validation.json` внутри комплекта. Контроль поставки дополнительно сравнивает исходники с упакованными копиями и Python-кодом внутри обработчика. Сам факт упаковки не заменяет эти проверки

Исправлены проверки границ MD, отсутствие новых методов в максимальном поиске после подготовки RAID/BitLocker и потеря карты ext4 при объединении одинаковых находок PhotoRec. Результаты с противоречивыми метаданными, изменённым источником или неполной картой не получают подтверждённое происхождение

Реальные телефоны, личные переписки, физические флешки и неисправные устройства здесь не проверялись. Новый ручной маршрут кнопок не подтверждён: ввод в окно в этой сессии был недоступен. Программные проверки WinForms выполнены. HPROF не добывается с телефона; найденные объекты не подтверждают удаление или принадлежность аккаунту. ext4 не проигрывает журнал; свободные блоки могли быть перезаписаны. MD предлагает только поддерживаемую согласованную конфигурацию для просмотра

Подробности: [HPROF](android-heap.md), [ext4](ext4.md), [Linux MD](raid-metadata.md). Универсальная замена всех платных редакций и восстановление любой удалённой переписки не установлены
