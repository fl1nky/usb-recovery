# Сборка разрозненных фотографий и видео

Два дополнительных прохода читают RAW-образ и сохраняют оригинальные байты вместе с картой исходных участков. Они не меняют образ и не перекодируют найденные файлы. В интерфейсе включаются галочками **«Сборка фрагментов фото»** и **«Сборка фрагментов MP4 / MOV»**; профиль «Максимальный» включает оба прохода

## Что поддерживается

| Формат | Уцелевшие данные, необходимые для сборки | Проверка |
|---|---|---|
| PNG | Сигнатура, IHDR, IDAT, IEND; обязательный PLTE для indexed color | CRC блоков, порядок и полнота zlib, размер строк, filter bytes, полное декодирование |
| JPEG | Baseline Huffman, таблицы и начало скана; restart islands либо ограниченный одиночный разрыв | MCU, DC/AC, Huffman, restart sequence, padding и EOI |
| MP4 / MOV | Карта samples/chunks в `moov`, заголовки и данные одного `mdat` | Границы контейнера, размеры, AVC NAL / MJPEG и согласованность карты |
| AAC-LC в MP4 | Согласованная геометрия соседних видеоблоков либо целого `mdat` | Ограниченная проверка структуры; произвольные отдельные AAC-фрагменты пока не собираются |

PNG поддерживает разнесённые сигнатуру, заголовок, обязательную палитру и блоки данных. Необязательная отделённая палитра truecolor не приписывается изображению без связи. Произвольный progressive JPEG, HEVC, fragmented MP4 и несколько `mdat` этим проходом не поддерживаются; другие включённые методы продолжают работать

Для JPEG без restart markers поиск одиночного разрыва ограничен небольшими файлами и ранними границами. Это не общий восстановитель всех JPEG с потерянной цепочкой кластеров

## Как понимать результат

Статус **«Кандидат сборки»** означает, что части образуют согласованную структуру. Он не подтверждает исходное имя, факт удаления, принадлежность частей одному исходному файлу или отсутствие подменённого содержимого

Несколько разных допустимых сборок отклоняются как неоднозначные. Равные копии одинаковых байтов можно объединить с сохранением ссылок на источник. При исчерпании бюджета проход остаётся неполным; отсутствие результата не означает уничтожение данных

У видео уцелевший `moov` не аутентифицирует кадры и звук. Ролик с затёртым AAC может пройти структурную проверку и даже воспроизводиться. При проверке результата нужно просмотреть весь ролик и прослушать звук

## Происхождение и продолжение

- `fragmented-photo-search.json` и `fragmented-media.json` связывают SHA256 результата с диапазонами образа
- Каталог принимает карту только для подходящего статуса, совпавшего содержимого и допустимых диапазонов
- Завершённые проходы можно продолжать через сохранённую сессию; ограниченный или отменённый проход не выдаётся за завершённый
- Непроверенные промежуточные файлы остаются `.partial`; при изменении источника публикация результата прекращается

## Проверки

Исходные модульные проверки, запуск переносимого обработчика и независимое сравнение — разные уровни проверки. Сводка текущей сборки хранится в отчётах приёмки; результаты на телефонах и физических флешках не выводятся из синтетических образов

Геометрические тесты медиа выполняются без внешнего декодера. Расширенный запуск `FragmentedMediaRecoveryTests` с `--audio-external` дополнительно требует разработческий FFmpeg и созданные им фикстуры; этот декодер не является зависимостью переносимой программы. Внешний прогон отдельно сравнивает исходные байты, видеокадры и PCM-звук
