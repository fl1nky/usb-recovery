# Новая JPEG-сборка и сохранённые результаты аналогов

2 ноября 2026 новая сборка прошла настоящий `RecoveryPipeline` на тех же пяти собственных образах по 8 МиБ. Выгрузки R-Studio Technician Demo 9.5.191861 и DMDE Console Free 4.4.4.842 сохранены от прежних опытов и не менялись. Нового сканирования этими программами не было; это не заявление об их последних версиях.

| Контрольный файл | Новая Recovery | Сохранённая R-Studio Demo | Сохранённая DMDE Free |
|---|---|---|---|
| Целый JPEG | Точные байты | Точные байты | Те же пиксели, лишний хвост |
| JPEG с разнесёнными restart-фрагментами | Точные байты | Повреждённый кандидат | Повреждённый кандидат |
| AVC MP4, две дорожки | Точные байты | Повреждённый кандидат | Не проверялось |
| MJPEG MOV, две дорожки | Точные байты | Повреждённый ролик и отдельные JPEG | Не проверялось |
| PNG с разнесёнными блоками | Точные байты | Находок в сохранённом сканировании нет | Не проверялось |

Результат: **Recovery 5/5 exact, сохранённая R-Studio 1/5**. На двух общих случаях DMDE — 0 exact и один полезный результат с совпадающими пикселями. V8 уже давала 5/5: на этой выборке новая сборка сохранила результат, а не повысила его.

Все десять выбранных этапов завершились в каждом случае. Общий статус пяти сессий — `finished_with_warnings`; предупреждения сохранены. Независимая проверка подтвердила байты пяти целевых файлов, 32 кандидата, 176 артефактов этапов и неизменность исходников, runtime, оценщика и старых выгрузок.

Полный конвейер использует также PhotoRec/TestDisk. Его результат нельзя целиком приписывать собственному JPEG-алгоритму. Здесь нет общего процента восстановления, сравнения скорости, UFS Explorer, реальных устройств или переписок Telegram.

## Что отдельно проверено для нового поиска JPEG

Добавлен ограниченный поиск baseline JPEG с двумя физическими разрывами, без restart-маркеров. Независимый серый контроль восстановлен побайтно. В RGB-контроле сохранены два разных декодируемых варианта с неизвестным оригиналом; проверены карта исходных диапазонов, отмена, продолжение и сохранение неопределённости в галерее.

На отдельном сложном `raw-scattered-baseline` исходный JPEG 45 234 B **не восстановлен**: получены два валидных варианта по 44 722 B. Этот случай не входит в пять строк таблицы, платные программы на новом контроле здесь не сравнивались. [Границы алгоритма](jpeg-baseline-gaps.md).

Для нового поиска использовать `tests/benchmarks/MediaBenchmark.cs` из репозитория, поставляемые manifest/config/FrameworkTarget и новый runtime. Передавать каждый из пяти case names явно: полный manifest содержит и другие случаи.

Измерение связывается с точными исходниками и runtime, а не с ещё не существовавшим в момент запуска commit. После измерения формат scorer закреплён CRLF для совпадения с историческим trusted SHA; нормализованный код тот же, проверка старых семи оценок повторно прошла без ослабления guards. В восстановленном proof Python считается данными и не исполняется.
