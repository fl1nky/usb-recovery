# Потоковая сборка крупных видео

Блоковая ветка больше не хранит целиком выходной файл или содержимое каждого выбранного блока. Она сохраняет смещения, длины, хеши и физические альтернативы. Сэмплы проверяются через отображение логических диапазонов на исходный образ; хеш полной сборки и запись результата выполняются последовательно. Исходный образ открыт только для чтения.

AVC проверяется по длинам и заголовкам NAL без чтения всей непрозрачной полезной нагрузки для каждого ложного совпадения. Ограниченный кэш заголовков устраняет повторное чтение одинаковых физических адресов. AAC, поддержанные HEVC и JPEG по-прежнему имеют ограничение на размер отдельного сэмпла. Синтаксическая проверка не декодирует PCM, CABAC или ссылки между кадрами и не подтверждает подлинность/удаление.

Первый проход ищет контейнеры. Индексы кодеков создаются по необходимости и конфигурации: AVC-файл больше не исчерпывает предел случайных однобайтных HEVC-префиксов. Крупная блоковая ветка заранее исключает гипотезы с участками без структурной опоры. Для каждой оставшейся ячейки достаточно одного обязательного заголовка; все готовые сэмплы и переходы между блоками всё равно проверяются. Разные допустимые байтовые результаты остаются неоднозначными.

Ремонт `moov` проверяет уже доступные части таблиц размеров, чанков, времени, композиционных смещений и ключевых кадров. Кэшируются только доказанно неподходящие одинаковые префиксы; известные нулевые диапазоны помогают не перечитывать одинаковое заполнение. Допустимые физические карты метаданных сохраняются отдельно. Если блоковая гипотеза не подходит, остаётся прежний поиск целых чанков. Исчерпание бюджета или подтверждённая неоднозначность не обходятся этим переходом.

## Границы

- Блоковая ветка: до 256 МиБ из 4096 ячеек по максимум 64 КиБ; размеры гипотез — 512–65536 байт. Это предел представления, а не обещание успешного восстановления файла такого размера.
- Отдельно ограничены 8192 сэмпла, 8192 состояния перебора, оценочный объём метаданных карты, число физических альтернатив и размер JSON-отчёта. Общий бюджет проверочного чтения — до 512 МиБ. Прежний поиск целых чанков сохраняет свой предел файла до 512 МиБ.
- `moov`: до 64 КиБ, восьми фрагментов, 64 физических карт и миллиона структурных проб. Отсутствующие байты, участки без опор и произвольные перестановки не угадываются.
- Поиск целых чанков имеет дополнительный предел проверок кандидатов — 16 × `MaxCandidates`; достижение предела означает `limited`, без полного результата и без утверждения, что данные уничтожены.
- `SourceReadBytes` отдельно учитывает запрошенное чтение образа, индексов и записи; `VerifiedBytes` относится к проверкам и потоковым хешам. Это не счётчики физических операций диска с учётом кэша Windows.
- Сохраняется отмена и удаление незавершённого собственного файла. Долговременный checkpoint этой новой ветки не заявляется: для него потребовалась бы отдельная привязка к полному источнику и параметрам.

## Воспроизводимая проверка

Генератор `tests/build_media_scale_fixtures.py` создаёт вне Git настоящие AVC/AAC-файлы 20–41 МиБ и обычные образы 128/256 МиБ. Фиксируются версия/хеш FFmpeg, команда, хеши исходников и независимые кадры/PCM. В программу передаётся только образ; эталонные карты используются исключительно тестами.

Корпус проверяет передний и разорванный хвостовой `moov`, выход свыше прежних 16/32 МиБ, независимый 24,5-МиБ mono-файл, нулевой/случайный фон, фазы 17/511, одинаковую копию, разные допустимые данные, утрату блока и несогласованные фазы. Ограниченный отрицательный результат отделяется от законченной проверки. Для точных результатов сравниваются весь SHA256, каждый кадр, весь PCM и каждый диапазон источника.

```powershell
python tests/build_media_scale_fixtures.py --destination .build/media-scale-fixtures-01 --ffmpeg tools/benchmarks/ffmpeg/ffmpeg-9.0.2-essentials_build/bin/ffmpeg.exe
```

`FragmentedMediaScaleTests` получает корень проекта, необязательный каталог корпуса и `--decode`. Обычная проверка использует уже подготовленный корпус без Python, FFmpeg и сети; `--decode` дополнительно запускает закреплённый FFmpeg с ограничениями времени и вывода. Большие бинарные образы в Git не добавляются.

Новая проверка масштаба относится к AVC/AAC. Крупные HEVC/JPEG, реальные накопители и преимущество над платными программами этим корпусом не измерены. Предыдущие опубликованные материалы V7 и его образы остаются неизменными.
