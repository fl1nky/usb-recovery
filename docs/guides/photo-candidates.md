# Как проверять найденные фотографии

В «Флешки и образы» открой «Все методы…» и включи сборку фрагментов фотографий. Результаты сохраняй на другом физическом носителе.

После поиска открой галерею:

- **Декодируется** — файл открывается, но это само по себе не доказывает полноту или первоначальное расположение фрагментов.
- **Неоднозначная сборка** — найдено несколько допустимых вариантов. Просмотри и сохрани нужные; программа не выбирает подтверждённый оригинал.
- **Повреждённый / частичный** — часть изображения может быть полезной. Такой результат не становится целым от появления миниатюры.

Миниатюры и встроенные изображения могут быть меньше оригинала. Одинаковые файлы объединяются по содержимому, ссылки на их источники сохраняются.

Для некоторых baseline JPEG добавлена сборка из трёх раздельных участков. Она ограничена файлами до 128 КиБ и поддержанными раскладками; это не универсальное восстановление любой фотографии. [Точные ограничения](../development/jpeg-baseline-gaps.md).

Поиск фотографий можно остановить и продолжить с сохранённой точки. Для этого сохраняй всю папку поиска и исходный образ: программа проверяет их перед продолжением.
