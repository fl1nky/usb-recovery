# APFS, RAID и BitLocker

Эти режимы читают обычные RAW-образы `.dd`, `.img`, `.raw`, `.bin`. Подключать или изменять исходную файловую систему не требуется. Результаты сохраняются отдельно; облачная загрузка не используется

При остановке незавершённый образ остаётся `.partial` и не выдаётся за готовый. Продолжение подготовки APFS/RAID/BitLocker с места остановки пока не реализовано

## APFS: извлечь файлы и прошлые версии

1. В разделе **«APFS · RAID · BitLocker»** выбери вкладку **APFS**, открой образ и нажми **«Проверить образ»**
2. Выбери найденный том и папку результатов. Для поддерживаемого зашифрованного тома введи свой пароль. Оставь **«Включать доступные снимки»**, если нужны прошлые версии; выбери количество последних снимков (по умолчанию 32)
3. Нажми **«Анализировать»**, затем **«Найденные файлы»** для просмотра и экспорта

Текущий файл, версия из снимка и запись из старого исправного checkpoint имеют разное происхождение. Наличие прошлой версии само по себе не доказывает удаление файла

## RAID: собрать логический образ

1. На вкладке **RAID** нажми **«Добавить образы»**. Расставь участников в известном порядке, укажи смещения; отсутствующий диск добавь отдельной строкой и отметь **«Нет»**
2. Выбери известные уровень, схему и размер блока. При наличии укажи логический размер и эталонную SHA256 всего массива. Выбери папку и достаточный лимит результатов
3. Нажми **«Собрать и найти»**. Флажок **«Сразу искать удалённые файлы»** запускает поиск по собранному образу; позже доступна кнопка **«Искать в образе»**

`0` в поле размера использует доступный размер зеркала RAID1 либо общую границу полных полос остальных уровней. Для авторазмера доступные размеры образов должны совпадать. Параметры массива программа не угадывает. Совпадение чётности и новая SHA256 не подтверждают исходный порядок дисков; известная эталонная SHA256 даёт дополнительную проверку

## BitLocker: расшифровать копию и искать файлы

1. На вкладке **BitLocker** открой образ, нажми **«Проверить образ»** и выбери том
2. Укажи свой 48-значный ключ восстановления, пароль тома либо файл `.BEK`. Выбери отдельную папку и лимит результатов
3. Нажми **«Анализировать»**. После подготовки можно сразу искать удалённые файлы либо открыть результат кнопкой **«Искать в образе»**

Доступная часть неполного тома публикуется как `decrypted-prefix.dd` с отметкой неполноты. Для неё выполняется поиск по содержимому доступных байтов; отсутствующий остаток тома не считается проверенным. Ошибка ключа или проверки метаданных не создаёт успешный расшифрованный образ

## Что реально проверено

Числа относятся к тестам адаптеров на обычных файлах. Проверка переносимого комплекта выполняется отдельно и должна быть связана с его текущими хешами

| Вариант | Подтверждено | Границы |
|---|---|---|
| APFS — 217 проверок, 13 тестов | Опубликованные macOS-образцы: текущие файлы, Unicode, hardlinks, чтение сжатых файлов, пароль шифрования с одним ключом; предыдущие версии из трёх явно выбранных снимков и исправный старый checkpoint. Раздельные extents, sparse holes и clone/private-id дополнительно проверены на сгенерированном APFS | Блок 4 КиБ. Не реализованы Fusion Drive, multikey/PFK, key rolling, sealed volumes, аппаратные ключи T2/Secure Enclave и поиск inode вне доступного дерева каталогов/снимков |
| RAID — 667 проверок | 0/1/5/6/10, поддерживаемые схемы, все допустимые сочетания отсутствующих участников, проверки зеркал/P/Q; поиск удалённого FAT12-файла по собранному образу | Явные порядок, схема, смещения. RAID10 только `adjacent-pairs`. Нет разбора метаданных контроллеров, автоматического определения параметров, reshape, Storage Spaces или LVM |
| BitLocker CBC 128/256 — часть 319 проверок / 16 тестов | Весь доступный префикс независимых опубликованных неполных образцов | Это не проверка полного независимого тома |
| BitLocker XTS и CBC+diffuser, 128/256 | Независимые образцы с явно заданным префиксом 64 КиБ | Проверка полного тома для этих вариантов не завершена |
| BitLocker: ключи и состояния | Recovery password, `.BEK`, ограниченные префиксы Vista/EOW, неверный ключ, повреждённые CRC и данные аутентификации, отмена и блокировка записи в источник | TPM без предоставленного ключа и обход защиты отсутствуют; paused/suspended-состояния отклоняются |
| Полный независимый Windows-образ | Проверка пока не завершена; в указанные числа не включена | Реальные пользовательские устройства не испытывались |

RAID5: `left-symmetric`, `right-symmetric`, `left-asymmetric`, `right-asymmetric`, `parity-first`, `parity-last`. RAID6: `left-symmetric`, `right-symmetric`, `parity-last`. В деградированном массиве может не остаться независимой избыточности для проверки восстановленных байтов

Независимый полный образ из набора dfVFS отклонён проверкой CRC метаданных и не учитывается как успешное восстановление. Полноразмерный образ с достроенным тестовым шифротекстом проверяет отдельную ветвь кода и не считается независимым образцом

Контрольные суммы APFS-метаданных и проверка ключевого материала BitLocker не гарантируют исходную целостность каждого файла или сектора. SHA256 экспортированного файла фиксирует полученную копию. Результаты требуют просмотра; превосходство над всеми платными программами не установлено

Проверка независимого полного тома средствами Windows на этой машине была остановлена до шифрования: ProtectKeyWithPassPhrase вернул FVE_E_NO_FEATURE_LICENSE (0x8031005A). Созданные только для теста VHD отсоединены; ограничения Windows не обходились. Это не успешный тест полного BitLocker-тома

Распаковка APFS проверяет границы chunks и выходных буферов; отдельный помощник ограничен 1536 МиБ памяти. При повреждении или достижении лимита результат не объявляется полным
