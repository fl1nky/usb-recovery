# Как пользоваться USB Recovery

## Запуск

1. Открой [страницу выпуска](https://github.com/fl1nky/usb-recovery/releases/latest) и в разделе **Assets** скачай файл `USB-Recovery-Windows-x64-….zip`.
2. Нажми правой кнопкой на ZIP и выбери «Извлечь всё».
3. Открой `USB-Recovery.exe` из извлечённой папки. Оставь остальные файлы рядом с ним.

## Найти фото на флешке

1. После удаления не записывай ничего на флешку. Если Windows предлагает исправить её или отформатировать, закрой это окно.
2. Открой **«Флешки и образы»**, нажми «Обновить» и выбери флешку по названию и объёму.
3. Кнопкой «Папка…» выбери папку на **другом физическом диске**. Для образа потребуется место размером с флешку, а для находок и временных файлов — дополнительное место.
4. Выбери профиль **«Фотографии»** и нажми «Начать восстановление». Программа читает флешку без записи на неё и ищет файлы в сохранённом образе.
5. Открой «Все файлы и экспорт» и выбери фильтр «Фотографии». Проверь фото, отметь нужные файлы и нажми «Копировать отмеченные». Для экспорта тоже выбери папку на другом физическом диске.

Для файлов разных типов начни со «Стандартного» профиля. Если флешку форматировали, попробуй профиль «После форматирования». [Все способы поиска](recovery.md)

## Продолжить или начать новый поиск

Чтобы сделать паузу, нажми **«Остановить»** и дождись завершения текущего чтения. После остановки или разрыва USB подключи прежнюю флешку, нажми **«Продолжить…»** и выбери папку той же сессии. Программа проверит сохранённое. Некоторые незавершённые этапы запустятся заново.

Для нового поиска сначала выбери профиль или галочки. Затем нажми **«Открыть образ…»** и укажи полный `usb.dd`. Результаты нового поиска сохранятся отдельно. Если остался только `usb.dd.partial`, сначала закончи съём через «Продолжить…».

## Найти запись в Telegram

1. Открой **«Telegram»** и нажми **«Анализировать»** для поиска в доступных папках на этом компьютере. Если у тебя есть экспорт, копия телефона или дамп, сначала укажи их через «Источник…».
2. Введи ключевые слова и нажми **«Найти»**. Для поиска по шаблону включи «Regex», например для запроса `рецепт|пирожк.*`.
3. Открой совпадение и посмотри его категорию и источник. Длинную запись можно прочитать через «Полный текст».

Поиск работает с локальными данными. Категория «Текстовый фрагмент» показывает совпавший отрывок с доступными сведениями об источнике. Отрывка может быть недостаточно, чтобы установить автора, дату и чат. [Поддерживаемые источники Telegram](media-and-telegram.md)

## Проверить PDF или видео

В «Все файлы и экспорт» выбери файл в списке. Для PDF доступны страницы и масштаб. Для видео доступны пауза, перемотка и громкость. Кнопка «Окно» открывает отдельный просмотр. Проверь нужные страницы или фрагменты видео перед копированием.

## Если ничего не нашлось

- Для флешки проверь фильтры каталога. Открой сохранённый образ и попробуй профиль «Максимальный» или дополнительные галочки в «Все методы…». [Как проверять кандидатов фото](photo-candidates.md)
- Для Telegram попробуй одно слово, сбрось фильтр категории и проверь нужную локальную копию через «Источник…».

Пустой результат относится к выбранному источнику и параметрам поиска. Сохрани образ и папку сессии для повторной проверки.
