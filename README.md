# Recovery

Восстановление файлов с флешек и поиск в локальных данных Telegram для Windows

**[Скачать программу](https://github.com/fl1nky/usb-recovery/releases/latest)**

## Запуск

1. Скачай ZIP из последнего выпуска
2. Распакуй архив целиком
3. Запусти `USB-Recovery.exe` — установка не нужна

## Флешка

1. Подключи флешку, открой **«Флешки и образы»** и нажми **«Обновить»**
2. Выбери флешку и папку на другом физическом диске, затем нажми **«Начать восстановление»**
3. Открой **«Все файлы и экспорт»**, проверь находки и сохрани нужные

## Telegram

1. В разделе **Telegram** нажми **«Анализировать»**. Для своей копии или дампа сначала выбери **«Источник…»**
2. Введи ключевые слова и нажми **«Найти»**

## APFS, RAID и BitLocker

1. Выбери вкладку: для APFS/BitLocker открой образ и нажми **«Проверить образ»**, для RAID добавь образы дисков
2. Укажи папку результатов, свой пароль/ключ либо известные параметры RAID
3. Нажми **«Анализировать»** или **«Собрать и найти»**, затем **«Найденные файлы»**

[Поддержанные варианты и ограничения](STORAGE-SUPPORT.md)

Всё обрабатывается локально. Не записывай ничего на исходную флешку. Программа ищет сохранившиеся данные; перезаписанные байты вернуть нельзя
