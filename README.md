# USB Recovery

Восстановление файлов с флешек и образов дисков. Поиск в сохранившихся локальных данных Telegram.

**[Скачать для Windows x64](https://github.com/fl1nky/usb-recovery/releases/latest)**

Распакуй ZIP целиком и запусти `USB-Recovery.exe`. Установка и отдельный Python не нужны.

[**Как пользоваться**](docs/guides/quick-start.md) · [Все способы поиска](docs/guides/recovery.md) · [APFS, RAID и BitLocker](docs/guides/storage.md) · [Сравнение с аналогами](docs/guides/comparison.md)

**Этап продукта — публичная бета.** Комплект Windows проверен на тестовых образах и файлах. Испытания на реальных флешках и телефонах ещё впереди.
