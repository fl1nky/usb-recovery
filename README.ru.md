# USB Recovery

[English](README.md) · [Русский](README.ru.md)

Восстановление файлов с флешек и образов дисков для Windows x64. Поиск в сохранившихся локальных данных Telegram.

**[Скачать актуальный ZIP для Windows x64](https://github.com/fl1nky/usb-recovery/releases/latest)**

Распакуй ZIP целиком и запусти `USB-Recovery.exe`. Оставь остальные папки рядом с ним. Отдельно устанавливать Python не требуется.

## Найти файлы на флешке

1. После удаления файла прекрати запись на флешку.
2. Открой **«Флешки и образы»**, выбери носитель и кнопкой **«Папка…»** укажи папку на **другом физическом диске**.
3. Для фото выбери **«Фотографии»** и нажми **«Начать восстановление»**. Программа сначала создаст образ флешки и выполнит поиск по этой копии.
4. Открой **«Все файлы и экспорт»**, проверь и отметь нужные файлы, затем нажми **«Копировать отмеченные»**. Для экспорта тоже выбери другой физический диск.

## Найти запись в Telegram

1. Открой **Telegram** и нажми **«Анализировать»**. Для своего экспорта, копии телефона или дампа сначала выбери **«Источник…»**.
2. Введи ключевые слова и нажми **«Найти»**. Для шаблона включи **Regex**, например `рецепт|пирожк.*`.
3. Проверь категорию и источник совпадения. Кнопка **«Полный текст»** открывает весь доступный текст.

Результат зависит от сохранившихся байтов и поддерживаемого формата. У текстового фрагмента могут быть неизвестны автор, дата и чат. Пустой результат относится к выбранному источнику и настройкам поиска.

Программа на стадии публичной беты. Проверки выполнены на контрольных файлах и образах. Настоящие флешки и Android/iPhone требуют отдельных испытаний.
