Бесплатный открытый программный комплекс для глубокого восстановления файлов с флешек, жестких дисков, RAID-массивов и дампов памяти. Восстановление фрагментированных медиафайлов, спасение метаданных современных файловых систем и извлечение удалённых сообщений и медиа из локального кэша Telegram.

**[Скачать готовую сборку для Windows x64](https://github.com/fl1nky/usb-recovery/releases/latest)**

Распакуйте ZIP целиком и запустите `USB-Recovery.exe`. Установка и сторонние библиотеки не требуются.

## Главные преимущества

- **Сборка фрагментированных файлов**: В отличие от линейного карвинга (PhotoRec), который обрезает или повреждает файлы, разбитые на несмежные кластеры, USB-Recovery применяет интеллектуальный алгоритм сборки из 2–3 фрагментов для JPEG, MP4/MOV, PNG и ZIP.
- **Сохранение структуры каталогов и имён**: Восстановление оригинального дерева папок и атрибутов файлов (MFT, FAT, ext4 inode, ReFS), а не просто свалка безымянных файлов (`f12345.jpg`).
- **Современные файловые системы и RAID**:
  - **APFS**: Извлечение файлов и снимков (snapshots), спасение метаданных непривязанных inode и экстентов.
  - **ReFS 3.14**: Разбор таблиц и B+ деревьев ReFS.
  - **ext4**: Спасение удаленных inode и анализ журнала JBD2.
  - **RAID**: Автоопределение и сборка Linux MD и SNIA DDF RAID 0/1/5.
  - **BitLocker**: Расшифровка при наличии пароля или ключа восстановления.
- **Глубокий поиск в кэше Telegram**: Парсинг 19 форматов локальных записей SQLite / LevelDB с привязкой медиафайлов к авторам и датам.
- **Продолжение сканирования (Checkpoints)**: Возможность приостанавливать и продолжать работу на терабайтных накопителях без повторного сканирования.
- **100% Offline и конфиденциальность**: Полное отсутствие телеметрии, сетевых запросов и скрытых трекеров.

## Быстрый старт

### Графический интерфейс (GUI)
1. Запустите `USB-Recovery.exe`.
2. Выберите образ диска или букву накопителя.
3. Нажмите **«Сканировать»** (или выберите специализированный профиль: «Фотографии», «Telegram», «APFS/RAID»).
4. Просмотрите дерево найденных файлов и нажмите **«Экспорт»**.

### Консольный режим (CLI)
Для автоматизации и использования в скриптах:
```powershell
# Получить справку по командам
.\USB-Recovery.exe --help

# Диагностика и определение структуры накопителя/образа
.\USB-Recovery.exe probe C:\images\disk.raw

# Сканирование с сохранением в целевую папку
.\USB-Recovery.exe scan C:\images\disk.raw -o C:\recovered --mode full
```

## Сборка из исходников

Требования:
- Windows 10/11 x64
- .NET Framework 4.8 (компилятор `csc.exe` встроен в Windows)
- PowerShell 5.1+

Сборка приложения:
```powershell
.\scripts\build-app.ps1
```

Запуск полного набора изолированных оффлайн-тестов:
```powershell
$env:__COMPAT_LAYER = 'RunAsInvoker'
.\tests\QualityOfflineTests.ps1 -ApplicationDirectory .build\app
```
