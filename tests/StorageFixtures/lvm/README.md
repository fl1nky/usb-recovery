# Native LVM2 fixtures

Public upstream Dissect volume 3.18 test data, AGPL-3.0; no personal devices.
Source: https://github.com/fox-it/dissect.volume/tree/3.18/tests/_data/lvm
Producer/version comments survive in each native LVM2 text metadata copy.

Linear: LVM2 2.02.175 (2017), 5 MiB PV. Mirror/thin: LVM2 2.03.18
(2022), native Linux-created 8/18 MiB PVs. Independent known payloads are
asserted by upstream tests/lvm/test_lvm.py, not generated by our reader.

Own tests add checksum damage, unequal/missing mirrors, changed checkpoint,
cycle/unknown version/dirty state and explicit sparse hole edge controls.
Allocation/refcount space maps and unrelated inactive thin-device trees are
not certified. No free-block undelete or reshape is claimed.
